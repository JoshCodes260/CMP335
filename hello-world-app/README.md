# Hello World App

This project is a simple web application that greets the user with a personalized message. It takes input from the user and displays "Hello [user input]" on the web page.

## Project Structure

```
hello-world-app
├── index.html       # The main HTML file containing the structure of the web page
├── styles.css       # The CSS file for styling the web page
├── script.js        # The JavaScript file for handling user input and updating the greeting
└── README.md        # This documentation file
```

## How to Run the Application

1. Clone the repository or download the project files.
2. Open the `index.html` file in a web browser.
3. Enter your name in the input field and click the "Greet Me" button.
4. The application will display a greeting message with your name.

## Functionality

- The application consists of an input field for the user to enter their name.
- A button is provided to submit the input.
- Upon clicking the button, the application retrieves the user's input and displays a greeting message on the page.
